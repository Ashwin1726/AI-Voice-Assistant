</div>

<p align="center">

retrieving previous context, executing productivity actions, managing reminders and tasks, and interacting through voice.

⚙️ QUICK START

</div>

01 — Clone

git clone https://github.com/YOUR_USERNAME/AESUN-AI-ASSISTANT.git
cd AESUN-AI-ASSISTANT

02 — Create Virtual Environment

python -m venv venv

03 — Activate

<b>Windows</b>

venv\Scripts\activate

<b>macOS / Linux</b>

source venv/bin/activate

04 — Install Dependencies

pip install -r requirements.txt

05 — Configure Environment

Create .env:

GEMINI_API_KEY=your_gemini_api_key
GROQ_API_KEY=your_groq_api_key

06 — Start AESUN

python app.py

Then open:

http://localhost:4000
